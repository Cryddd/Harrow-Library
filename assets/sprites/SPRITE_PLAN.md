# Sprite Production Plan

## Characters

- Player: 4-direction idle/walk, 24x32 or 32x40, backpack and student clothing.
- NPCs: one reusable body rig with palette variants, plus key silhouettes for Maren, Rajan, Yuki, Kai Echo, and the hidden SYSTEM_7 entity.

## Objects

Prioritize:

1. Reception desk, bookshelves, stairs, doors.
2. Workstations, monitors, whiteboards, server racks.
3. Lamps, plants, books, mugs, keyboards, sticky notes.
4. Mystery props: redacted boards, encrypted terminals, archive cabinets, Kai workstation.

## Animation Hooks

- Monitors: blinking cursor and terminal scroll.
- Servers: LED pulse.
- Plants: subtle sway.
- Lamps: warm flicker.
- Floor 3: glitch shader on SYSTEM_7 assets.
